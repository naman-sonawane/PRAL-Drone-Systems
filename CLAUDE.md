# PRAL Drone System — Project Instructions

## Workflow: draft in chat first

**Everything must be drafted in chat and discussed before it is written to a file.**

- Do not create or edit docs/specs/PRDs directly. First present the draft (or the substantive changes) in the chat response.
- Wait for the user to react, refine, or approve. Only write to a file once the content has been discussed.
- This applies to all documents (vision docs, PRDs, execution specs) and to significant edits of existing ones.
- Small mechanical fixes the user explicitly asks for (typo, rename, move a file) can be done directly.
